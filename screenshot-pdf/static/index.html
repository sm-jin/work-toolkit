Screenshot + PDF

드래그해서 PDF 한 쪽이 될 영역을 지정하세요
사용 순서
  1. 캡처할 PC(맥미니 또는 윈도우)에서 문서를 첫 쪽으로 띄워 둡니다. 로그인이 필요한 사이트는 직접 로그인합니다.
  2. 웹 화면을 같은 PC에서 열었다면 3초 뒤를 고르고, 그사이 캡처할 창을 앞으로 가져옵니다.
  3. 화면 가져오기를 누르고 문서 영역을 드래그합니다.
  4. 페이지 넘김 방식을 고르고 넘김 테스트로 확인한 뒤, 뷰어를 첫 쪽으로 되돌립니다.
  5. PDF 파일 이름과 저장 폴더를 정하고 캡처 시작. 끝나면 그 폴더에 PDF 하나로 저장되고, 아래 작업 목록에서도 받을 수 있습니다.
