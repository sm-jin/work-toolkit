# Screenshot + PDF (맥미니 · 윈도우)

화면에 띄워 둔 문서(로그인이 필요한 사이트는 사용자가 직접 로그인)를, 웹 화면에서 영역만 지정하면
쪽을 넘기며 자동 캡처하고 **PDF 하나**로 만들어 줍니다. 기본으로 OCR을 해서 PDF에서 글자 검색·복사가 됩니다.
맥미니(홈서버)와 윈도우 PC 모두에서 같은 프로그램이 돕니다 — [윈도우에서 쓰기](#윈도우에서-쓰기) 참고.

```
[맥북 / 아이패드 / 폰 브라우저]  ──집 Wi-Fi 또는 Tailscale──▶  [맥미니]
  좌표 지정 · 시작/중지 · PDF 다운로드                         ├─ Chrome: 문서 뷰어 (직접 로그인)
                                                               └─ 캡처 서버 (이 프로젝트, 터미널에서 실행)
                                                                    screencapture → 쪽 넘김(키/클릭) 반복
                                                                    → img2pdf → ocrmypdf(OCR) → PDF
```

- 계정 정보·쿠키·세션은 전혀 다루지 않고 **화면 픽셀만** 캡처합니다.
- 캡처, PDF 생성, OCR 모두 그 PC 안에서만 처리합니다 (외부 전송 없음).
- 웹 화면은 리모컨일 뿐이고, 실제 캡처와 키 입력은 **브라우저가 떠 있는 그 PC**에서 서버 프로그램이 합니다.
  (웹 페이지만으로는 다른 창에 키를 보낼 수 없어서, 로컬에서 도는 프로그램이 꼭 필요합니다.)
- 쪽이 다 그려질 때까지 기다렸다 찍고, 넘겨도 화면이 그대로면 마지막 쪽으로 판단해 자동 종료합니다.

## 1. 설치 (맥미니에서 한 번)

1. 맥미니 터미널에서 코드를 받습니다 (Private 저장소라 처음 한 번 GitHub 로그인이 필요합니다):
   ```bash
   git clone https://github.com/sm-jin/work-toolkit.git ~/work-toolkit
   ```
   이후 업데이트는 `cd ~/work-toolkit && git pull`.
2. 설치:
   ```bash
   cd ~/work-toolkit/screenshot-pdf && ./setup.sh
   ```
   Homebrew로 `ocrmypdf`(tesseract 포함)를 설치하고, 한국어 OCR 데이터와 파이썬 가상환경을 준비합니다.
3. **권한 주기** — *시스템 설정 > 개인정보 보호 및 보안*에서 서버를 실행할 터미널 앱(터미널 또는 iTerm)을 켭니다.
   - **화면 및 시스템 오디오 녹음**: 캡처용
   - **손쉬운 사용**: 쪽 넘김(키 입력·클릭)용

   권한을 준 뒤에는 터미널을 완전히 종료(⌘Q)했다가 다시 여세요.
4. 실행:
   ```bash
   ./run.sh
   ```
   터미널에 `http://<맥미니>.local:8765/?token=...` 형태의 접속 주소가 나옵니다. 다른 기기에서 이 주소를 한 번 열면 30일 동안 로그인이 유지됩니다.

### 맥미니 권장 설정

- **모니터가 없다면 HDMI 더미 플러그(4K)**를 꽂아 두세요. 화면 해상도가 곧 캡처·OCR 품질입니다.
  모니터 없이 화면 공유로만 쓰면 해상도가 낮게 잡히는 경우가 많습니다.
- 캡처 중에는 디스플레이 꺼짐·잠자기를 자동으로 막습니다(`caffeinate`). 단, **화면이 잠기면 캡처가 불가능**하므로 잠기면 자동 중지됩니다.
- 부팅 때 자동 실행하려면 `start.command`를 *시스템 설정 > 일반 > 로그인 항목*에 추가하세요.
- 다른 방에서 맥미니 브라우저에 로그인만 하려면 맥북의 Finder에서 ⌘K → `vnc://<맥미니>.local` (화면 공유)로 접속하면 됩니다.

## 2. 사용법

1. 맥미니 Chrome(Safari도 가능)에서 문서를 **첫 쪽**으로 엽니다. 로그인이 필요한 사이트는 직접 로그인합니다.
   뷰어를 최대한 크게(쪽 맞춤, 전체 화면) 띄울수록 OCR이 정확해집니다.
2. 다른 기기에서 웹 화면을 열고 **화면 가져오기** → 문서 영역을 드래그 → **테스트 캡처**로 확인합니다.
3. 쪽 넘김 방식을 고릅니다.
   - **키보드 키**: →, ↓, Page Down 등 (뷰어가 지원하면 가장 안정적)
   - **'다음' 버튼 클릭**: 상단의 *다음 버튼 위치* 모드로 바꾸고 화면에서 버튼을 클릭
   - **넘김 테스트**로 실제로 넘어가는지 확인한 뒤, 뷰어를 첫 쪽으로 되돌립니다.
4. **PDF 파일 이름**과 **저장 폴더**를 정하고 **캡처 시작**.
   - 저장 폴더는 경로를 직접 입력하거나(`~/Documents/이사회자료`처럼) **찾아보기…**로 고릅니다.
     찾아보기 창은 **캡처 PC 화면**에 뜹니다. 비워 두면 앱 기본 폴더(`data/jobs/<작업ID>/`)에 저장됩니다.
   - 없는 폴더는 새로 만들고, 시작하기 전에 쓸 수 있는 폴더인지 먼저 확인합니다.
   - 같은 이름의 PDF가 이미 있으면 덮어쓰지 않고 `이름 (2).pdf`처럼 번호를 붙입니다.
   - 끝나면 그 폴더에 `이름.pdf` 하나가 생기고, 작업 목록에서도 받거나 **Finder에서 보기**로 열 수 있습니다.
   - **OCR**을 켜 두면(기본) 이미지 위에 보이지 않는 글자 층이 들어가 검색·복사가 됩니다. 끄면 이미지만 든 PDF가 됩니다.
     OCR이 실패하거나 중간에 중지하면 이미지만 든 PDF로 저장하고 작업 목록에 알려 줍니다.
   - 숫자 설정의 허용 범위: 넘긴 뒤 대기 0.2~30초, 최대 쪽수 1~3000쪽, 시작 전 대기 0~60초 (웹 화면에도 표시)

> 웹 화면은 맥미니가 아닌 **다른 기기**에서 여는 것을 권장합니다. 맥미니에서 직접 열면
> 웹 화면 창이 캡처할 창을 가리거나 키 입력을 가로챌 수 있습니다.

### 중지하는 방법

- 웹 화면의 **중지** 버튼
- 맥미니에서 마우스를 **화면 왼쪽 위 모서리**로 옮기기
- 맥미니에서 다른 앱을 앞으로 가져오면 자동 중지 (화살표 키가 엉뚱한 앱에 입력되는 것을 막기 위해)

### 중간에 멈췄을 때

그때까지 찍은 쪽은 작업 목록의 **PDF 다시 만들기**로 PDF를 만들 수 있습니다. 전체가 필요하면 첫 쪽부터 다시 캡처하세요.

## 윈도우에서 쓰기

맥미니에 모니터가 없거나 평소 쓰는 윈도우 PC에서 바로 하고 싶을 때. 서버를 그 윈도우 PC에서 실행하고,
같은 PC의 브라우저에서 `http://localhost:8765`로 웹 화면을 엽니다.

1. [Python 3](https://www.python.org/downloads/) 설치 (설치 화면에서 **Add python.exe to PATH** 체크)
   - 막 나온 최신 버전보다 한 단계 아래(예: 3.13, 3.14)를 권장합니다. 아주 최신 버전은 일부 패키지의 윈도우용 설치 파일이 늦게 나와 설치가 실패할 수 있습니다.
2. 코드를 받습니다: `git clone https://github.com/sm-jin/work-toolkit.git` (나중에 `git pull`로 업데이트).
   받은 `work-toolkit\screenshot-pdf` 폴더에서 **`setup.bat`** 더블클릭
   → 파이썬 패키지와 Tesseract OCR(winget)을 설치합니다. winget이 안 되면 [UB-Mannheim Tesseract](https://github.com/UB-Mannheim/tesseract/wiki)를 직접 설치하세요.
3. **`check.bat`** 으로 점검 (화면 캡처·모니터·잠금 상태·OCR 확인, 키 입력은 보내지 않음)
4. **`run.bat`** 실행 → 창에 나온 주소를 브라우저로 엽니다.

맥과 다른 점:

- 화면 기록/손쉬운 사용 같은 **권한 설정이 필요 없습니다.**
- 좌표는 **물리 픽셀** 단위입니다. 디스플레이 배율(125%, 150%)이어도 자동으로 맞춥니다.
- OCR은 ocrmypdf 대신 **Tesseract로 바로** 검색 가능한 PDF를 만듭니다.
- 기본으로 **그 PC에서만** 접속됩니다(`127.0.0.1`). 폰에서도 조작하려면 `run.bat`에 `set SHOTPDF_HOST=0.0.0.0`을 넣고,
  윈도우 방화벽 창이 뜨면 *개인 네트워크*만 허용하세요.

같은 PC에서 웹 화면과 캡처할 창을 함께 쓰는 요령:

- **화면 가져오기 옆에서 "3초 뒤"**를 고르고 누른 다음, 3초 안에 캡처할 창을 앞으로 가져오세요. 웹 화면 창이 찍히지 않습니다.
- 캡처를 시작하면 카운트다운 뒤 문서 영역을 한 번 클릭해 캡처할 창을 앞으로 가져오고 진행합니다.
  웹 화면과 캡처할 문서는 **서로 다른 브라우저 창**이어야 합니다(같은 창의 탭이면 안 됨).
- 캡처 중에 다른 창을 클릭하면 안전을 위해 자동으로 멈춥니다. 모니터가 두 대면 웹 화면을 다른 모니터에 두면 편합니다.
- 원격 데스크톱(RDP)으로 조작한다면 캡처가 끝날 때까지 RDP 창을 **최소화하거나 연결을 끊지 마세요**.
  화면이 그려지지 않아 캡처와 키 입력이 멈춥니다.
- 회사 PC라면 보안 정책상 프로그램 설치나 로컬 서버 실행이 막혀 있을 수 있습니다.

## 3. 보안

- 웹 화면은 **접속 토큰**으로 보호됩니다 (HttpOnly 쿠키). 토큰을 바꾸려면 `data/token.txt`를 지우고 서버를 다시 실행하세요.
- **공유기 포트포워딩은 하지 마세요.** 집 밖에서 쓰려면 [Tailscale](https://tailscale.com)을 맥미니와 쓰는 기기에 설치하고
  `http://<맥미니의 Tailscale 이름>:8765`로 접속하세요 (구간 암호화). Tailscale로만 열어 두려면
  `SHOTPDF_HOST=<맥미니 Tailscale IP> ./run.sh`로 실행합니다.
- 집 Wi-Fi 안에서는 HTTP(평문)이므로 공용 Wi-Fi 같은 망에서는 Tailscale을 통해서만 접속하세요.
- 캡처 원본은 `data/jobs/`(권한 700)에, PDF는 정한 저장 폴더에 저장됩니다. 작업을 **삭제**하면 캡처 원본은 지워지고
  직접 정한 저장 폴더의 PDF는 남습니다. 맥미니에는 FileVault를 켜 두세요.
- **iCloud Drive·Dropbox·OneDrive 같은 동기화 폴더**를 저장 폴더로 고르면 PDF가 클라우드에 올라갑니다.
  맥에서 *데스크탑 및 문서 폴더 iCloud 동기화*를 켜 두었다면 `~/Documents`, `~/Desktop`도 해당됩니다.
- 회사 정보보안 규정이 이사회 자료의 로컬 사본 보관을 허용하는지 미리 확인하세요.

## 4. 문제 해결

| 증상 | 해결 |
|---|---|
| 캡처가 검은 화면이거나 바탕화면만 찍힘 | 터미널 앱에 *화면 및 시스템 오디오 녹음* 권한 → 터미널 재시작 |
| 쪽이 넘어가지 않음 / 1쪽만 찍고 끝남 | *손쉬운 사용* 권한 확인, "영역 클릭해 포커스" 체크, 키 대신 '다음' 버튼 클릭 방식으로 변경 |
| 덜 그려진 쪽이나 같은 쪽이 두 번 찍힘 | *넘긴 뒤 대기(초)*를 늘리기 (2~3초) |
| 시작할 때 "저장 폴더에 쓸 수 없습니다" | 맥: *개인정보 보호 및 보안 > 파일 및 폴더*(또는 전체 디스크 접근 권한)에서 터미널 허용. 외장 디스크가 연결돼 있는지 확인 |
| 갑자기 캡처가 멈춤 | 맥미니 화면에 macOS 권한 확인 창이 떠 있지 않은지 확인 |
| (윈도우) 캡처가 검거나 쪽이 안 넘어감 | 화면 잠금·RDP 최소화 여부 확인, 문서를 띄운 브라우저를 관리자 권한으로 실행하지 않았는지 확인 |
| OCR 품질이 낮음 | 뷰어 확대, 고해상도(Retina/4K) 디스플레이 사용, 한국어 문서면 OCR 언어를 *한국어 + 영어*로 |

## 5. 구성

```
screenshot-pdf/
  setup.sh / run.sh / start.command   맥: 설치 · 실행 · 로그인 항목용
  setup.bat / run.bat / check.bat     윈도우: 설치 · 실행 · 점검
  app/server.py     웹 서버(FastAPI), 토큰 인증, API
  app/runner.py     캡처 루프: 넘김 → 렌더링 완료 대기 → 저장 → 마지막 쪽 감지 → PDF/OCR
  app/screen/       운영체제별 캡처 · 키/클릭 입력 · 잠금 확인
    mac.py            screencapture, Quartz 이벤트, 화면 기록/손쉬운 사용 권한
    win.py            Pillow ImageGrab, SendInput, DPI 인식
  app/pdfbuild.py   img2pdf(무손실 이미지 PDF), ocrmypdf 또는 tesseract(글자 층 추가)
  app/check.py      설치 점검 (python -m app.check)
  app/store.py      설정 · 토큰 · 작업 폴더
  static/           웹 화면 (좌표 지정, 실행, 작업 목록)
  data/             (자동 생성) token.txt, config.json, jobs/<작업ID>/pages/*.png, *.pdf
```

환경변수: `SHOTPDF_HOST`(기본: 맥 `0.0.0.0`, 윈도우 `127.0.0.1`), `SHOTPDF_PORT`(기본 `8765`), `SHOTPDF_DATA`(기본 `./data`),
`SHOTPDF_TESSERACT`(tesseract.exe 경로를 직접 지정할 때)
